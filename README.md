🍔 Food Order

**Next.js / React.js / TailwindCSS / Redux Toolkit / Apollo Client / GraphQL / Hygraph / JWT**

A modern and responsive food ordering web application that allows users to explore meals, manage their shopping cart, authenticate securely, and complete their orders through a streamlined checkout experience.

#### 🔹 Features:

- Dynamic food menu with **category filtering**, **discounts**, **countdown timers**, and **user reviews**
- Integrated **GraphQL API** using **Apollo Client** with **Hygraph CMS**
- Implemented **SSR** (Server-Side Rendering) and **SSG** (Static Site Generation) for improved **performance** and **SEO**
- Built a fully functional shopping cart using **Redux Toolkit**
- **Phone Authentication & OTP** with OTP expiration and resend functionality
- **JWT Authentication** with secure session management using **HttpOnly Cookies**
- Complete **Checkout Flow** with subtotal, discounts, shipping costs, and final price calculation
- **Order Management & Tracking** with payment status handling
- Applied **Protected Routes** to restrict access to authenticated users
- Designed a **modular, reusable, and maintainable component architecture**
- Fully **responsive UI** optimized for desktop, tablet, and mobile devices
